Desafio Técnico - C#

Este repositório contém a solução de um desafio técnico com três exercícios, desenvolvidos em C# (.NET) como aplicações de console.

Exercícios
desafio-1: cálculo de comissão de vendas a partir de um arquivo JSON, com menu por vendedor.

desafio-2: lançamento de movimentações de estoque (entrada e saída) de produtos de um arquivo JSON.

desafio-3: cálculo de juros (2,5% ao dia) a partir de um valor e de uma data de vencimento.
